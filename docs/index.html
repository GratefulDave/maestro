01 / 08

Small control plane. Hard boundaries.

Prompts propose work; Python owns execution. lane_state.stage, immutable artifacts, and receipt-backed publication remain explicit and inspectable.

Plan

Approved before execution

Planning skills emit one executable plan. The compiler checks schema, DAG, ownership, and acceptance. No plan gate|review|ship or bootstrap verb.

Isolation

Persistent role worktrees

All five persistent role agents remain visible in Herdr, use dedicated host-authenticated profiles, and start inside role-specific Git worktrees. Checkout-local role instructions limit each agent to its assigned tree while native repository tools remain available.

Acceptance

Sealed tests, then merge once

Private tests seal before building. Each accepted lane merges exactly once into the run integration ref. Publication is receipt-backed.

Trace

Stage plus artifacts

SQLite under runtime_state_root stores lane_state.stage and immutable artifacts. Attempts and operator escapes are not authority.

02 / 08

Execution model

A lane is ready when its stage is not MERGED or WAITING_FOR_USER and every needs lane is MERGED. Author/review/build may overlap; merges are serialized.

01Startrun start writes the plan revision, DAG projection, and PLANNED lanes, then the integration ref.
02Private testsAuthor → review → seal. Builder never sees private source.
03Build / reviewBuilder then code review. REVISE returns redacted findings; PASS advances.
04MergeExactly-once integration merge from the immutable candidate SHA.
05PublishFinal review, then receipt-backed publication to main.
Resume. Process death restarts the current incomplete stage from its last immutable input. A still-running role pane may reconnect as transport by proved project/run/lane/role identity. run amend invalidates only the affected stage and transitive dependents. No retry/skip/abandon/cancel verb.

04 / 08

Lane stages

lane_state.stage is the sole durable workflow authority. Git SHAs identify bytes, not stage. Every legal transition commits an immutable artifact atomically with the next stage.

PLANNED→ WRITING_TESTS→ REVIEWING_TESTS→ TESTS_SEALED→ BUILDING→ REVIEWING_CODE→ READY_TO_MERGE→ MERGED or WAITING_FOR_USER
Verdicts

PASS or REVISE

Reviewer verdicts are artifact data, not stages. REVISE returns to the author or builder with redacted findings. Review is a lane stage, never a synthetic DAG node.

Resume

Last immutable artifact

run resume continues the next incomplete stage from the last accepted artifact. After PAUSE it restores that stage. After AMENDMENT_REQUIRED the lane stays waiting. No retry budget, skip, abandon, or cancel verb.

05 / 08

Visible Herdr launcher

Every agent node runs in a visible pane. Route selects the CLI; model selects the intelligence behind it. Those axes never collapse. Only omp and Claude routes with valid signed route receipts are admitted. The OMP flag is --profile, not --pm-profile.

OperationContract
launch(spec)Place or reconnect one of the five exact role panes in the project+run workspace and lane tab. Keep the authenticated OMP or Claude process on the host, bind it to one stable role checkout or private tree, grant only Bash, and prove the container image and hook before launch. Every command enters a disposable no-network container; missing confinement refuses launch.
poll(handle)Report starting, running, idle, exited, or gone. Idle after output is normal and is not completion. Herdr state is advisory; the last complete structured transcript envelope synthesizes terminal exit truth.
close(handle)Transport only. Success leaves the role pane, process, working tree, and session available for later stages. Not a Maestro operator cancel verb and not a lane stage.
reclaim(token)On scheduler restart, rediscover the five deterministic role identities first, live-check them, and resubmit the current stage from its immutable input. Recreate only confirmed dead or typed agent_not_found roles. Never adopt or rename legacy stage/attempt panes, malformed observations, unreachable Herdr, or mismatched placement as current roles.
classify(error)Map launch faults into fixed configuration, authentication, transient, protocol, or execution classes.
provision(worktree)Run ecosystem setup after worktree creation and before baseline or pre-gate measurement.
wait_for_interactive_agent(name)Block on herdr agent wait <name> --until idle --timeout, the documented readiness gate for coding agents. No undocumented status field is polled and no per-agent startup banner is scraped from the pane.
submit_agent_prompt(target, text)Production submits with pane send-text then a separate pane send-keys enter. An @ completion popup ate atomic Enter. Proof is an actor transcript turn, not the pane revision meter and not agent_status. A repaint is not a submitted turn.
Prompt proof. Submission is two pane calls, not an atomic Enter. The composer’s @ completion popup swallowed Enter when it arrived in the same packet as the text. Treat a transcript turn as proof; treating a meter tick or agent_status as delivery is a fake.
06 / 08

Runtime and repository binding

Every run binds one external runtime_state_root to one product Git common directory. Template trees and deployment worktrees are different roles; source/deployment confusion refuses before a run is created.

01ResolveCanonicalize --repo, --main-ref, and the external runtime-state root.
02RefuseReject template-source execution, unsafe permissions, symlinks, and runtime/product path overlap.
03BindPersist repository identity, initial main SHA, plan revision, integration ref, and lane projection atomically.
04Recheckrun resume|amend|status revalidate the descriptor and repository fingerprint before reading or mutating run state.
External state

Never under the product worktree

The ledger, vault, locks, receipts, artifacts, and ephemeral worktree roots live under the bound runtime_state_root, never under the repository being built.

One repository

Exact Git identity

All stage worktrees, candidate refs, the run integration ref, final review, and target-main publication belong to the same bound Git common directory.

Immutable lineage

Refs identify bytes

Candidate, integration, and publication SHAs are artifact inputs and receipt subjects. They never become a second stage or mutable recovery branch.

Refusal

No inferred recovery

Descriptor mismatch, missing receipts, external main movement, stale stage input, or wrong repository refuses explicitly. Resume does not adopt unknown agents or dirty/out-of-scope worktrees. Proved live role transport may reconnect.

07 / 08

Operator CLI

Frozen surface. Invoke the deployment copy only. Template-source run creation refuses RUN_REPOSITORY_MISMATCH. No bootstrap, plan gate/review/ship/finalize, retry, skip, abandon, or cancel verb.

# frozen operator surface
$ uv run adws/maestro.py run start <approved-plan> --repo <target-worktree-root> --main-ref <ref>
$ uv run adws/maestro.py run resume <run-id>
$ uv run adws/maestro.py run amend <approved-plan> --run <run-id>
$ uv run adws/maestro.py run status <run-id>
Amend, not bootstrap. run amend is the only verb that may apply a PLAN_AMENDMENT. Publication after a passing final review is receipt-backed on refs/maestro/publications/<run-id>/<fingerprint>; main at the same SHA without that receipt is refused.
