QUIESCENCE_UNPROVEN

Stay blocked, or reclaim the same generation

  • Absent envelope — stays QUIESCENCE_UNPROVEN until an explicit retry. Bare resume neither grants budget nor relaunches completed work.
  • Undispatched claim — undispatched_quiescence_attempts names a generation that never crossed dispatch; claim_undispatched_attempt reopens that same attempt_no, allocating nothing.
  • Late envelope — identity-bound success continues the attempt. Adopt only on exact pane, cwd, session, correlation, role, and generation.
  • Leftover reclaim — worktree.stale_attempt_worktrees reclaims leftover attempt trees on disk.
  • lane_phase clear — LifecycleStore.resume_run reopening a no-evidence node clears lane_phase.
  • Pre-dispatch NODE_TIMEOUT — retries if never dispatched; not QUIESCENCE_UNPROVEN.

PROOF · ABSENCE

Transcript turn, not the pane meter

  • Prompt proof — the actor transcript turn. A pane revision advance is a repaint; agent_status is not proof. Production: pane send-text then a separate pane send-keys enter.
  • workspace_not_found — absence for every pane in that workspace. Cached lane layouts are invalid; they are dropped together, not reused.
