Persistent role topology

Herdr is transport. One parent run Space per (repository identity, run_id), labelled <repository-basename>-<first-four-run-hash-characters> — example FDAdb-e892. Linked children use the exact authored lane_id and appear only when that lane first dispatches. Role panes are lazy: tester, tester-reviewer, builder, code-reviewer, and integration-reviewer in the last topological lane. Rediscovery adopts exact Herdr report-metadata identity, never a label.
