Current · Architecture

Persistent role topology

Herdr is transport. Each lane is a genuine linked child workspace beneath the invoking source Space, not an ordinary tab. worktree list --workspace <invoking-id> proves the source repository and parent identity; an invalid or missing parent refuses rather than creating an unrelated Space. The lane's deterministic detached, no-checkout Git anchor belongs to that invoking repository. Role execution checkouts and publication remain bound exclusively to the target repository, even across repositories. Children use the authored lane_id. Role panes are lazy: tester, tester-reviewer, builder, code-reviewer, and integration-reviewer in the last topological lane. Resume restores previously materialized role shells before native gates can block dispatch, without starting agents or sending prompts. Exact run/lane/role metadata proves reuse; surviving owned panes migrate with their PTY and agent intact, while absent panes are recreated. Whole-run publication remains the cleanup boundary: idle proof and confirmed session rename precede child closure, owned UI anchors are unregistered through their own Git repository, and the invoking parent is never closed.
