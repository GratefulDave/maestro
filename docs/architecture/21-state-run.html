Derived run state

What the run is, from node rows, cancel_requested, and scheduler_liveness. RunOutcome is a different vocabulary, written once when a live scheduler declares.

SCHEDULER_TYPES.RUNOUTCOME

Declared once when the scheduler stops

  • ACCEPTED — some MERGED, no stragglers, acceptance_result True. Derived state for this shape is MERGED, not ACCEPTED.
  • BLOCKED — residual class (RESIDUAL_OUTCOME). Empty run, failed acceptance, or any combination nobody designed.
  • CANCELLED — cancel_requested or every node CANCELLED. Written by total_run_outcome; not the derived CANCELLED below.
  • STUCK — the §11.2 liveness backstop, declared with work still in flight. Not a RUN_STATES member.

LIFECYCLE.DERIVE_RUN_STATE

ABANDONED is not CANCELLED

  • ABANDONED — scheduler_liveness is False and (a node is RUNNING, or latest_outcome is None). No scheduler, nothing will declare.
  • CANCELLED — cancellation finished: every node absolutely terminal, and cancel_requested or latest_outcome is CANCELLED.
  • QUIESCENT — settled without that cancel signal: all-terminal mix that is not MERGED, or the fallthrough with no live work.
