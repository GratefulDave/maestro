Historical annotation · REVIEW_BUDGET_EXHAUSTED

Grant is not BLOCKED → PENDING

  • Grant — retry --force/--grant leaves the rejected candidate, handoff, worktree, and actor generation on this attempt. State stays BLOCKED.
  • Resume after grant — only absence-proven run resume may return that same attempt to the frontier.
  • A grant is not a ceiling removal and not a new attempt number.

Historical annotation · SEMANTIC_BUDGET_EXHAUSTED

Bare resume floors spend → PENDING

  • Joins _RESUME_REFRESHED_BLOCK_REASONS.
  • Bare run resume raises retry_spend_floor / lane_retry_spend_floor and returns the node to PENDING.
  • Floor, not grant, not ceiling removal. Scheduler retry reads floored lane spends. These cards annotate the superseded SVG only.
